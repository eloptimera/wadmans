# Bilder på grundaren och teamet

Lägg en eller flera bilder här (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`). De visas automatiskt i
sektionen "Bakom företaget" på startsidan och på Om oss. Finns inga bilder visas bara texten, och
i utvecklingsläge syns en markerad bildplats så att det är lätt att se var bilden hamnar.

Tips: stående bild, minst 1000 px bred, ljus och naturlig. Filnamnen sorteras alfabetiskt.
